# LLM Architect Studio 🧠🛠️

An interactive, end-to-end web application that breaks down every stage of building, training, aligning, and deploying Large Language Models from scratch.

## Project Structure
- index.html
- css/style.css
- js/app.js
- README.md

## Modules Included
1. Pipeline Map
2. Tokenizer Studio
3. Architecture Inspector
4. Pre-Training Simulator
5. SFT & Alignment Lab
6. Quantization & Deployment Calculator
